## Struttura della repository

La cartella `02_Statistiche` costituisce la repository Git di Sempreanorma S.r.l.

La repository è suddivisa in cartelle dedicate ai diversi contesti di lavoro, ad esempio `01_5SAN` e `02_Configuratore`, ciascuno associato al relativo branch.

Ogni cartella contiene:

* il progetto R dedicato (`.Rproj`);
* i dati nella cartella `00_Data`;
* il codice R nella cartella `01_Code`;
* gli output prodotti nella cartella `02_Output`.

Quando si cambia progetto o contesto di lavoro, è necessario passare al branch corrispondente prima di aggiungere, modificare, rimuovere o effettuare il commit dei file.
